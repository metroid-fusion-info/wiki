### Patches

- Debug Mode patches to enable the debug mode in the [American/European/Australian](mfu-debug.ips) as well as the [Japanese](mfj-debug.ips) versions of the game. An explanation of using the debug mode can be found on [The Cutting Room Floor](https://tcrf.net/Metroid_Fusion/Debug_Menu).

- [Faster Fusion](https://metroidconstruction.com/hack.php?id=530), a hack that removes all dialogue from the game. The forum thread additionally contains a patch with debug mode enabled.

- [Fastest Fusion](https://metroidconstruction.com/hack.php?id=780), a hack that removes all dialogue from the game as well as removing most uncontrollable speedrunning related RNG. It is an allowed hack on the [Category Extensions](https://www.speedrun.com/fusion_ce?h=fastest-fusion-any-any&x=q256mo8k-yn2065el.lr37wvwl).

- [Japanese Practice Hack](https://gitlab.com/cluekitty/mf_practice_rom/-/releases), a hack that provides several tools for easier practicing. Includes a room timer, noclip, makes the invisible target points visible and allows one save state.

- [Metroid Fusion Hacks On Metroid Construction]( https://metroidconstruction.com/hacks.php?sort=5&dir=desc&filters[]=MF&filters[]=Unknown&filters[]=Boss+Rush&filters[]=Exploration&filters[]=Challenge&filters[]=Spoof&filters[]=Speedrun%2FRace&filters[]=Incomplete&filters[]=Quick+Play&filters[]=Improvement&filters[]=Vanilla%2B&filters[]=Total+Conversion&num_per_page=50). They're sorted by release date.

- The [Metroid Fusion Decompilation](https://github.com/metroidret/mf/).


### Misc

- A Lua Script to [visualize various hitboxes](https://gitlab.com/cluekitty/metroid-fusion-lua/-/blob/main/bizhawk/fusion-hitbox-emuhawk2-9-1.lua) in the game. Made for Bizhawk 2.9.1 or higher.

- A Lua Script to [visualize an input viewer as well as show IGT/percentage on the end screeen](https://gitlab.com/cluekitty/metroid-fusion-lua/-/blob/main/bizhawk/fusion-input-display.lua). Made for Bizhawk.
